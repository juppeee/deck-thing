Spotify

Titel, Cover und Steuerung laufen ohne Anmeldung. Für Like, deine Bibliothek, Smart Shuffle und Spotifys eigenen Lautstärkeregler verbindest du dein Konto einmal.

VerbundenLike, Bibliothek, Smart Shuffle und Lautstärke sind aktiv.
  1. Spotify-Entwicklerseite öffnen und mit deinem Konto anmelden. Voraussetzung ist Spotify Premium.
  2. „Create app“ klicken. Name und Beschreibung sind egal, z. B. „Deck Thing“.
  3. Diese Redirect URI eintragen und auf „Add“ klicken:
    http://127.0.0.1:8765/callback
  4. Bei „Which API/SDKs“ Web API ankreuzen, Bedingungen annehmen, speichern.
  5. Client ID von der Seite der App kopieren und hier einfügen:
    Warte auf die Anmeldung im Browser …

Ein Client-Secret wird nicht gebraucht. Die Zugangsdaten bleiben auf diesem PC.
