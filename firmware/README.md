# Firmware

The device interface is written with [LVGL 9.5](https://lvgl.io). The same code
in `ui/` runs on the ESP32-S3 board and in a Windows simulator.

| Folder | Contents |
|---|---|
| `ui/` | Screens, theme and fonts — shared between simulator and board |
| `ui/images/` | Parts of the start animation, generated by `companion/tools/make_logo.py` |
| `ui/fonts/` | Fonts converted with `lv_font_conv` (Figtree, Lucide, Material Icons); originals and licences in `ui/fonts/src/` |
| `link/` | Frame protocol to the companion app — shared between simulator and board |
| `board/` | ESP-IDF project (PlatformIO) for the Waveshare ESP32-S3-Touch-LCD-4.3 |
| `sim/` | Windows simulator: LVGL's own Windows driver plus a TCP client for the companion app |
| `third_party/lvgl` | LVGL v9.5.0 (git submodule) |
| `third_party/cJSON` | cJSON 1.7.18 (vendored, MIT) |

## Simulator

Needs Visual Studio 2022 with the C++ workload and CMake.

```bash
git submodule update --init
cd firmware/sim
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
build\Release\deck_thing_sim.exe
```

An 800 × 480 window opens. The mouse acts as touch, the **mouse wheel turns the
knob** and the **middle button presses it**. Start the companion app and the
simulator connects on its own (`127.0.0.1:8766`), showing what Spotify plays.

## Board

Waveshare ESP32-S3-Touch-LCD-4.3, ESP-IDF 5.5 through PlatformIO.

```bash
git submodule update --init
cd firmware/board
pio run -t upload
```

Use the board's **USB** port — it both flashes the firmware and talks to the
app. The **UART** port carries the log (`pio device monitor`).

| Part | Handled in |
|---|---|
| RGB panel, two frame buffers swapped after each finished frame | `src/main.c` |
| GT911 touch | `src/gt911.c` |
| CH422G IO expander (backlight, resets) | `src/ch422g.c` |
| USB link to the app (core 0) | `src/usb_link.c` |

Settings that matter, all in `sdkconfig.defaults`: PSRAM octal at 80 MHz with
code and constants run from PSRAM, `CONFIG_ESP32S3_DATA_CACHE_LINE_64B` (the
picture jumped down without it), IRAM-safe panel interrupt and an 800 ms
interrupt watchdog. `sdkconfig.defaults` only applies when `sdkconfig.ws43` does
not exist yet — delete that file after changing the defaults.
